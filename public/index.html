Set up in four steps

Goodreads no longer provides a supported developer OAuth flow, so the Vercel endpoint reads the official RSS feed using credentials supplied by each MCP client. For a guided setup, run one command below; a temporary browser opens on your computer and your password is never requested by Goodreads MCP.

Let your browser do the busywork

Sign in directly to Goodreads, press Enter, and the local helper finds your profile ID and RSS link. Nothing is sent to Vercel, and setup asks before changing your AI client configuration.

npx -y goodreads-mcp setup --client claude
npx -y goodreads-mcp setup --client codex
1

Sign in directly on Goodreads

Authenticate in a headed browser yourself. Never give a setup tool your password or ask it to read, export, or save session cookies. Then open your Goodreads profile. Open Goodreads ↗

Manual fallback: paste your profile URL here to extract the public user ID locally in this page.

2

Let the assistant find both values

The guided setup can derive the numeric user ID from your profile, then open My Books and find its RSS link. It should parse the key value in memory without opening or printing the secret-bearing URL.

3

Keep the RSS key private

The assistant should report only “user ID found” and “RSS key found.” Once the RSS link is visible, it must not capture screenshots, browser snapshots, network logs, the current URL, or the link target. The key stays out of chat, logs, and shell history.

4

Confirm the local config change

A local configuration tool should show you the destination and variable names, ask before writing, and never display the secret values. Restart your client afterward. Never commit these values to source control. If the RSS link has no key parameter, leave GOODREADS_RSS_KEY unset. 

export GOODREADS_USER_ID="12345678"
export GOODREADS_RSS_KEY="your-private-rss-key"

Choose a transport

Goodreads MCP works with compatible clients over local stdio or hosted Streamable HTTP. Configuration syntax varies, so use the equivalent fields in your client's MCP settings.

Local stdio

Run the package locally and pass the two environment variables to the process. 

command: npx
args: -y, goodreads-mcp
environment:
  GOODREADS_USER_ID
  GOODREADS_RSS_KEY

Hosted HTTP

Point your client at the endpoint and map local environment variables to these request headers. 

url: https://goodreads-mcp-chi.vercel.app/mcp
headers:
  X-Goodreads-User-ID: GOODREADS_USER_ID
  X-Goodreads-RSS-Key: GOODREADS_RSS_KEY
No MCP OAuth login is required. This stateless endpoint does not use OAuth. It reads the user ID and optional RSS key from request headers and does not store them. Never provide a Goodreads password or session cookie.
